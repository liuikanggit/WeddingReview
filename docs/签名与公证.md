# macOS 签名与公证

没有 Apple 开发者账号时，包只有 ad-hoc 签名，别人首次打开要「右键 →打开」。
有了账号做**签名 + 公证（notarization）**后，对方双击直接打开，零提示。

配置只需要一次：把证书和 API Key 存成 GitHub Secrets，CI 会自动启用。
`.github/workflows/release.yml` 里已经写好了判断——**没配 secrets 也能正常出包**，
只是回退到 ad-hoc，不会因为缺少配置而构建失败。

## 一、先确认账号归属

如果证书来自**别人的账号**，要留意两点：

- **个人账号（Individual）无法添加团队成员**，只有公司账号（Organization）可以。
  所以通常只能让对方导出证书给你用。
- 签出来的包，开发者身份显示的是**证书持有者**的名字。
  如果这个应用以后要正经对外分发，最好还是用自己的账号。

## 二、导出证书（`.p12`）

证书持有者在自己的 Mac 上操作：

1. Xcode →「Settings」→「Accounts」→ 选中账号 →「Manage Certificates」
2. 左下角 `+` →「Developer ID Application」（**不是** Apple Distribution，
   那个是上架 App Store 用的，做本地分发要 Developer ID）
3. 打开「钥匙串访问」，找到这张证书，**连同它下面的私钥一起**右键导出为 `.p12`，设一个密码
4. 把 `.p12` 转成 base64 文本，方便存进 Secrets：

   ```bash
   base64 -i certificate.p12 | pbcopy
   ```

## 三、创建公证用的 API Key（`.p8`）

比共享 Apple ID 密码干净：权限最小、可随时吊销、不涉及双重验证。

1. 登录 [App Store Connect](https://appstoreconnect.apple.com/) →「用户和访问」→「集成」→「App Store Connect API」
2. 生成一个 Key，角色选 **Developer** 即可
3. 下载 `.p8` 文件（**只能下载一次**），记下 Key ID 和 Issuer ID
4. 同样转成 base64：

   ```bash
   base64 -i AuthKey_XXXXXXXX.p8 | pbcopy
   ```

## 四、填进 GitHub Secrets

仓库 →「Settings」→「Secrets and variables」→「Actions」→「New repository secret」：

| Secret | 值 |
| --- | --- |
| `APPLE_CERTIFICATE` | `.p12` 的 base64 文本 |
| `APPLE_CERTIFICATE_PASSWORD` | 导出 `.p12` 时设的密码 |
| `APPLE_SIGNING_IDENTITY` | 形如 `Developer ID Application: 某某 (TEAMID)` |
| `APPLE_API_KEY` | API Key ID（那串 10 位字符） |
| `APPLE_API_ISSUER` | Issuer ID（UUID 格式） |
| `APPLE_API_KEY_PATH` | `.p8` 的 base64 文本 |

`APPLE_SIGNING_IDENTITY` 的准确值可以在证书持有者的机器上查：

```bash
security find-identity -v -p codesigning
```

配好后推一个 tag，出来的 `.dmg` 就是签名并公证过的了。验证：

```bash
spctl -a -vvv -t install /Applications/拾光笺.app
# 通过的话会显示 source=Notarized Developer ID
```

## 五、本地要用签名打包

本地 `./scripts/build-mac.sh` 默认走 ad-hoc。想在本地出正式包，先把证书装进钥匙串，
再把 `src-tauri/tauri.conf.json` 里的 `bundle.macOS.signingIdentity` 从 `"-"` 换成
完整的证书名，并设置公证所需的环境变量：

```bash
export APPLE_API_KEY=XXXXXXXXXX
export APPLE_API_ISSUER=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
export APPLE_API_KEY_PATH=/path/to/AuthKey_XXXXXXXX.p8
./scripts/build-mac.sh
```

日常自己用不必这么麻烦，ad-hoc 足够；要发给别人再用 CI 出正式包即可。
